# dmc-chat-client

This is a React.js project that displays in-game messages from the destroymc.net Minecraft server via websockets.

## Install

```
git clone https://github.com/codrum/dmc-chat-client.git
cd dmc-chat-client
npm install
npm start
```

## Usage

Website should be live at
```
http://localhost:3000
```
